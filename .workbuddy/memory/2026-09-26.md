## 钢琴页动态景深（DOF）修复

### 根因（持续朦胧模糊的四个叠加因素）
1. 远场 CoC 饱和：`clamp(|vz-focusDist|*uDof,0,1)*uDofMax`，地面盘半径 16m，下半屏全饱和 ~14 texel 模糊
2. 常驻边缘移轴 `def` + CA 色散与焦点无关，四周永远轻糊
3. 焦点拾取 120ms 节流 + 只在 raycast 命中钢琴时更新 → 鼠标离开模型焦点冻结、迟滞
4. 15 texel 模糊半径只摊 9 tap → 颗粒散景

### 用户决策（grill-me 访谈结论）
- 模糊强度参数维持现状（三套风格 dof/dofMax/edge 不动）
- 焦点机制：每帧轻量代理求交（钢琴包围球+键盘盒+地面平面），指哪清哪含地面
- 景深本质（用户原话）：鼠标所在距离的一个范围清楚，过近过远都模糊
- 兜底：运镜期焦点锁运镜注视点；鼠标离开画布/悬停 UI/未命中→钢琴中心 (0,0.9,-0.6)

### 代码改动
- `pianoGrade.ts`：新增 `uFocusRange`(0.25) uniform；CoC 改为 `clamp((|vz-f|-uFocusRange)*uDof,0,1)*uDofMax`——焦深带内完全清晰，带外原斜率渐糊，总量不变
- `PianoScene.tsx`：删 120ms 节流全模型 raycast；改每帧 `Ray.intersectSphere/Box/Plane` 代理求交（rootBox 上扩 0.95m 裕量防琴盖全开）；`PIANO_FOCUS_DEFAULT` 兜底；pointerleave 处理；运镜期跟焦 camTmp.target
- `PianoPostProcessing.tsx`：焦点阻尼 kf 9→14（~70ms 收敛）；uFocusDist 初值改为首帧真实焦点距离（消灭开场先糊）

## 钢琴页景深修复（会话完成）
- **真正的根因（两层）**：① `PianoPostProcessing` 的 EffectComposer 两个 render target 共享一张深度纹理,而 OutputPass/ShaderPass 依赖全局 `autoClear=true` → 绑定 rt1 时把共享深度清成 1.0；② MSAA(samples=4) 深度 resolve 在 SwiftShader/ANGLE-D3D 上静默失败 → 深度纹理恒为远平面 → Grade 的 CoC 恒饱和 → 整页恒定重模糊("一直朦胧"的真因)。
- **修复**：渲染期间 `gl.autoClear=false`(RenderPass 有显式 clear 不受影响) + `samples:0`(场景深度直写深度纹理)。诊断利器：shader 内临时输出 `d0` 灰度图 + 焦点扫描法(锐点在 60=vz 兜底值→深度空)。
- **焦点机制**：每帧代理求交(琴体 AABB+键盘盒+地面平面,clamp 盒顶 1.45m 防开盖峰值) → focusRef → 后处理 kf=14 阻尼驱动 uFocusDist；三段式：运镜期锁注视点/交互期跟鼠标/离开画布回钢琴中心(0,0.9,-0.6)。shader 加 uFocusRange=0.25 焦深清晰带。
- **代理求交的两个坑**：包围球在相机贴近时迎面切点比琴面凸 0.5m+(改用 AABB)；默认琴盖全开会把盒顶抬到 2.3m(钳制)。
- **验证设施**：`scripts/ab.mjs`(CDP 交互驱动,常驻 chrome --remote-debugging-port=9222,步骤间不断开) + `scripts/sharpness.py`(纯 stdlib PNG 解码+Laplacian 方差清晰度)。**坑：`vite preview` 后每次 `page.goto` 加新 query 拿到的是上一个构建(reload 才可靠)；uniform 属性拦截冻结法要兼容 value/accessor 描述符,否则 getter 崩掉 useFrame 假死(canvas 冻结导致对照实验全作废)。**
- 磁带页 post.js 同款配置存在相同隐患(AO 靠局部 autoClear=false 幸存,bloom/output 后深度仍会被清),待后续统一修复。
- tsc 仅剩 Film 页 5 个既有错误(与本次无关)；终版 console 零错误。

# uikit / sceneMode 反编译留档（hero↔selected-work 无缝合并用）

来源：`.decomp/shader-main.js`（compose 组件）、`.decomp/fetch/chunks/0wb~eqgmow_3x.js`（pagesConfig）。

## 1. transitionTypeMap（数值映射）

```
{fade:0, direct:1, overlay:2, below:3}
```

## 2. compose 场景 pass 的 current/next 分支（原文语义）

逐帧（`sceneMode.value=0` 之外）：

```js
e = I + 1                                  // 下一页索引
t = fround(ranges[I]?.y ?? 0)              // 当前页 range.end
r = fround(transitionLengths[e] ?? 0)      // 下一页 transitionLength
i = e < 7 && !(scroll <= fround(t - r))    // scroll 越过 (curEnd - nextTL) 即进入转场
sceneMode = i ? 2 : 1
currentTexture = pages[I]; currentLens/Border/Saturation = pages[I] 原值
若 i：nextTexture = pages[e]；nextLens/Border/Saturation = pages[e] 原值；
      nextTransitionType = transitionTypes[e]；transitionRangeEnd = ranges[I].y；transitionLength = r
```

着色器（`a` = 当前页采样，`s` = 下一页采样）：

```js
l = smoothstep(transitionRangeEnd - transitionLength, transitionRangeEnd, scroll)
u = mix(a, s, l)                     // type 0 (fade) 与 type 1 (direct)
type == 2 → u = mix(a, s, s.a)       // overlay：下一页 alpha 门控（about-us 折页）
type == 3 → u = mix(s, a, a.a)       // below：当前页 alpha 门控（reveal/tie）
```

## 3. UI 纹理合成（同一条场景 pass 内）

```js
a = barrel(uv, lens, border)                       // UI 与场景共用桶形畸变 uv
s = mix(texture(uiTextureLight, a), texture(uiTextureDark, a), uiModeTransition)
s *= clamp(uiTransition, 0, 1)
// 解析 hover 高亮：
logoRegion   = a.x*res.x < 240        && (1-a.y)*res.y > res.y-96   // 左下
pageAction   = a.x*res.x > res.x-220  && (1-a.y)*res.y > res.y-96   // 右下
logoRegion   → s *= 1 + logoHoverTransition*0.25
pageAction   → s *= 1 + pageActionHoverTransition*0.25
```

- `uiTransition`：motion 值（spring），UI 显隐标量，不是滚动映射。
- `uiModeTransition`：motion 值，light→dark 交叉淡化标量。
- uiMode 只有 about-us 是 `dark`，其余页全 `light`。

## 5. 页面渲染门控（renderRange）

```js
r = t.renderRange ?? t.range;  if (r.start < a && r.end > a) ex.add(t.id)  // 才渲染该页
renderRange.start = range.start - (renderOffset?.beforeStart ?? 0)
```

即 office 页从 scroll 1.3 起开始渲染（正好是胶片蒙版起点）；projects 从 0.1 起（喂显示器屏幕）；hero 恒渲染。

## 6. 杂项

- 场景相机工厂 `nZ({type:"perspective", fov,near,far,basePosition,baseRotation,aspect})`。
- `getMouseOffset()` = (0.5 − mouseX01, 0.5 − mouseY01)，mouseY01 = 1 − clientY/h。
- subPage（项目详情）体系（subPageType/subPageTransition）不在本次范围。
- 已知偏差：about-us 段内容边界（shredStart 等）按纸面高度动态算（原站公式），静态页长 7.3367 在极端宽高比下会与效果窗口漂移——维持现状。
